# LINH PHỐ — Design Package v1.0

1. `LINH_PHO_GDD_v1.md` — Đặc tả concept, gameplay, thế giới, nhiệm vụ, quy chuẩn kỹ thuật, UI/UX, kiến trúc, roadmap và kiếm tiền.
2. `LINH_PHO_AI_PROMPT_KIT.md` — Prompt 00 (master) và Prompt 01–12 để giao AI code theo module.
3. `LINH_PHO_BLENDER_ART_BIBLE.md` — Quy chuẩn đồ họa 3D khả thi, danh mục asset, pipeline GLB, 6 prompt Blender.

Đọc GDD trước, chạy Prompt 00 + Prompt 01, kiểm thử trước khi chuyển module.

Trong game: WASD hoặc phím mũi tên để đi bộ; giữ Shift khi di chuyển để chạy nhanh. Thả Shift để trở về đi bộ. Tốc độ đi 2,2 m/s, chạy 5,4 m/s; nhân vật dùng animation Quaternius Walk và Jog_Fwd đã chỉnh trong Blender.
